神通寰宇

用一份可追溯的日报，
跟进领域内每天的进展。

按研究方向追踪论文、预印本、临床试验、监管与产业动态，生成带原始出处的 HTML 日报。

选择安装方式 ↓ 查看日报演示

从检索到日报

检索规则可配置
从神经科学、肿瘤学或重症医学预设出发，按期刊、字段、关键词与布尔逻辑定义检索范围。
结果可以追溯
汇总期刊 RSS、PubMed、预印本和临床监管来源，查看检索状态、本地历史及每条结果的原始链接。
定时检索与分享
定时生成日报，按需通过邮件、飞书或企业微信推送。文献数据可导出为 JSON 或 BibTeX。
主题建模
LDA + t-SNE 主题景观，支持中英文语料、LLM 主题标签和逐点查看原文。
会议 & 学者追踪
内置会议日历、截止倒计时，并可按姓名追踪特定学者的新作。

日报演示

按版块浏览检索结果，从论文条目回到期刊或数据库。

Agent Skills

两个可安装的 Agent Skill：一个面向研究者/团队，一个面向主题领域。

Scholar / Lab Profile

面向一名研究者、实验室或研究团队：从公开出版物、ORCID 与 OpenAlex 生成该团队可能感兴趣的检索配置。

打开 scholar-profile ↗

Topic / Field Profile

面向一个主题或领域，循循善诱地收集同义词、子领域、排除词、来源和期刊，生成并 validate 检索配置。

打开 topic-profile ↗

高度定制 · 本机轻量 · 自动分享

从检索到分发，全部围绕你的研究习惯配置。

高度定制化
学科、布尔检索、期刊、会议、学者追踪、信息源均可配置；支持中英文与多语言。
本机轻量部署
单机 Python/Tauri 即可运行，不需要先搭服务器；Docker 作为可选部署方式。
自动分享同好
日报可通过邮件、飞书或企业微信分享；也可部署到私人服务器，用手机浏览器查看完整交互报告。
