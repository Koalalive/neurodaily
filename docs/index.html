神通寰宇

用一份可追溯的日报，
跟进领域内每天的进展。

按研究方向追踪论文、预印本、临床试验、监管与产业动态，生成带原始出处的 HTML 日报。

选择安装方式 ↓ 查看日报演示

从检索到日报

检索规则可配置
从神经科学、肿瘤学或重症医学预设出发，按期刊、字段、关键词与布尔逻辑定义检索范围。
结果可以追溯
汇总期刊 RSS、PubMed、预印本和临床监管来源，查看检索状态、本地历史及每条结果的原始链接。
定时检索与分享
定时生成日报，按需通过邮件、飞书或企业微信推送。文献数据可导出为 JSON 或 BibTeX。

日报演示

按版块浏览检索结果，从论文条目回到期刊或数据库。

安装与运行

Windows / Linux

Windows 可用 EXE 或 MSI 安装。Linux 可用 AppImage 或 DEB。

查看最新正式版 ↗ 系统要求 ↗

macOS

使用 Homebrew 安装，再用 neurodaily web 打开本机工作区。

Homebrew 安装指南 ↗

Docker / 命令行

面向本机、服务器和定时任务，支持用 CLI 生成离线演示或真实日报。

项目文档

Python 负责检索与定时任务，FastAPI 提供本地工作区，Jinja2 生成独立 HTML 日报。Windows 和 Linux 用 Tauri 封装本地服务。
