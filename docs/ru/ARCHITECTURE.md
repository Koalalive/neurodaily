# Архитектура

> [中文](../ARCHITECTURE.md) · [English](../en/ARCHITECTURE.md) · **Русский**

Цель: **одна машина, одно развёртывание, читаемый ежедневный дайджест**. Каждый этап деградирует мягко: сбой одного источника не должен уничтожать отчёт.

## 1. Поток данных

```
launchd / cron / CLI / Web
        └─> digest.run(mode="daily"|"manual")
              ├─ источники: журналы RSS, PubMed, arXiv, bioRxiv,
              │             ClinicalTrials.gov, openFDA, политика, финансирование
              ├─ теги → дедупликация → ранжирование → разделы
              ├─ окно статей (36 ч ежедневно / 168 ч вручную)
              ├─ метрики журналов (OpenAlex + импорт официального CSV)
              ├─ «В этот день» (zh/en/ru, перевод LLM с кэшем)
              └─ HTML → output/ → почта + webhook
```

## 2. Модули

| Модуль | Ответственность |
|---|---|
| `digest.py` | Оркестрация, окна, дедупликация, разделы, `save_report` |
| `sources.py` | Реестр источников и загрузчики |
| `journal_metrics.py` | OpenAlex `2yr_mean_citedness` + официальный импорт |
| `onthisday.py` | Исторические события, резервная ротация, перевод |
| `render.py` / `templates/` | HTML-отчёт Jinja, значки метрик, i18n |
| `mailer.py` | SMTP STARTTLS/SSL, письмо + вложение |
| `webhooks.py` | Feishu / WeCom |
| `webapp.py` | Панель, API настроек, ручной запуск, `/api/push` |
| `settings_page.py` | GUI настроек (конфиг +推送 + расписание) |
| `cli.py` | `run`, `demo`, `serve`, `metrics`, `export`, `deepen` |

## 3. Деградация

- Сбой источника фиксируется в `health`, запуск продолжается.
- Нет ключа LLM → отчёт на китайском без перевода, без падения.
- Нет JCR/CAS → показывается OpenAlex 2yr mean citedness с пометкой, что это **не** JCR IF.
- Сбой почты/webhook не критичен: файл отчёта создаётся первым.

## 4. Точки расширения

- Новый источник: загрузчик в `sources.py` или запись `sources[]` в `config.json`.
- Новый журнал: добавить в `journals[]`; метрики подтягиваются по ISSN.
- Новый язык: расширить `OTD_LABELS` и промпты в `onthisday.py`.
